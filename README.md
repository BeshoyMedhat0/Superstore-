# 📊  Superstore 2019 Sales Analysis

A Power BI sales analysis project based on the Sample Superstore dataset.

I worked on the data to understand sales performance, profitability, products, regions, and returned orders. I then created an interactive Power BI report to present the main results and insights.

---

## 🎯 Project Objective

The main goal of this project was to analyze sales data and understand:

- 💰 Sales and profit performance
- 📈 Monthly sales trends
- 📦 Product and sub-category performance
- 🌎 Sales by region
- 🔄 Returned orders and return rate
- 📊 Key business performance indicators

---

## 🔧 What I Worked On

- 🧹 Prepared the data for analysis
- 📊 Analyzed total sales and profit
- 💵 Calculated profit margin
- 📈 Analyzed monthly sales trends
- 📦 Analyzed sales by category and sub-category
- 🏆 Identified top products by sales
- 🌎 Compared sales across regions
- 🔄 Analyzed returned orders
- 📍 Analyzed returned orders by city and region
- 📊 Built interactive Power BI dashboards
- 📋 Created a final report with key insights

## 📌 Key Results

Some of the main results shown in the dashboard:

- 💰 Total Sales: **2.30M**
- 💵 Total Profit: **286.40K**
- 📊 Profit Margin: **12.47%**
- 📈 YoY Growth: **46.88%**
- 🧾 Total Orders: **9.99K**
- 🔄 Returned Orders: **296**
- ⚠️ Return Rate: **2.96%**

---

## 💡 Key Insights

The final report highlights:

- 🌎 The **West** region generated the highest share of sales at **33.1%**.
- 📦 **Phones** and **Chairs** were among the top-performing sub-categories by sales.
- 🔄 The dashboard recorded **296 returned orders**.
- 📈 Sales showed an upward trend toward the last quarter.
- 💰 Total sales reached **2.30M** with a **12.47% profit margin**.
