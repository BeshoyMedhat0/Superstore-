# 📊  Superstore 2019 – Power BI & DAX Analysis

A Power BI sales analysis project based on the Sample Superstore 2019 dataset.

In this project, I prepared and analyzed the sales data using Power Query and Power BI. I also used DAX to create measures and calculated columns, then built interactive report pages to analyze sales, profit, products, regions, and returned orders.

---

## 🎯 Project Objective

The main goal of this project was to build an automated Power BI report for analyzing business performance.

The analysis focuses on:

- 💰 Sales performance
- 💵 Profitability
- 📈 Sales growth
- 📦 Product performance
- 🌎 Regional performance
- 🔄 Returned orders
- 📊 Business KPIs

---

## 🔧 What I Worked On

### 🧹 Data Preparation

I imported the Sample Superstore 2019 dataset into Power BI and prepared the data using Power Query.

The preparation included:

- 🔍 Reviewing the dataset
- 🧹 Cleaning and transforming the data
- 📅 Preparing date fields
- 🏷️ Preparing product and category information
- 👥 Preparing customer and segment information
- 🌎 Preparing regional information
- 🔄 Preparing return-related data

---

## 🗂️ Data Model & Date Hierarchy

I created a proper data model and prepared the date structure for time-based analysis.

The date hierarchy allows the analysis to be viewed by:

- 📅 Year
- 📊 Quarter
- 📆 Month
- 🗓️ Day

---

## 📐 DAX Measures

I created DAX measures to calculate the main business KPIs and perform time-based analysis.

The project includes measures such as:

- 💰 Total Sales
- 💵 Total Profit
- 📊 Profit Margin %
- 📈 Running Total
- 📅 Year-over-Year Growth (YoY)

These measures were used throughout the report to analyze sales and profitability.

---

## 🧮 Calculated Columns

I also created calculated columns using DAX, including:

- 📊 Profitability Category
- 🚚 Shipping Delay

These columns were used to support the analysis and reporting.

## 💡 Key Insights

- 🌎 The West region generated the highest share of sales at **33.1%**.
- 📦 Phones and Chairs were among the top-performing sub-categories by sales.
- 🔄 The report recorded **296 returned orders**.
- 📈 Sales showed an upward trend toward the last quarter.
- 💰 Total sales reached **2.30M** with a **12.47% profit margin**.
